AI 활용 방법 가이드

🤖 대표 공유 스킬 · 도구
  • Agentic(언웨이즈) 스킬 — 24시간 멈추지 않고 목표 달성. GitHub 공개 스킬. 퇴근 전 돌려놓고 다음날 결과 확인
  • GSTACK — 다방면 관점 제공, 코딩·기획 시 활용. 계획 먼저 세우고 OK 받은 뒤 실행하도록 설계
  • Hiku(바이코) API — 인스타/유튜브 크롤링, 10달러 충전으로 꽤 활용 가능. 이메일 가입 후 충전해줄 예정
  • Claude Fable + Opus 토론 — 두 모델이 서로 토론·스터디하게 하여 인플루언서 선별 근거 강화
📋 AI로 인플루언서 선별 프로세스 — 7일 과정
  • 1차: 평균 CPV + 핏 맞는 CPV 두 개 기준으로 후보 뽑기
  • 2차: 핏(키높이 부츠 등 조건) 맞는 애만 재추출
  • 3~6차: GSTACK(다방면 관점) + Claude Fable·Opus 토론(인플루언서 선별 근거 강화)으로 단계적 기준 올려가며 탈락시키기
  • 가이드 제작: 잘된 레퍼런스·안된 레퍼런스 추출 후 학습 → GSTACK으로 가이드라인 작성 → Claude Fable·Opus 토론으로 최종 검증
  • 최종: 대표가 소수 리스트 확인 후 결정 → 가이드라인 컨펌

커넥팅 채널 콘텐츠 기획

🎬 콘텐츠 구성 (해외 인플루언서 × 한국 커넥팅)
